
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a Hangman game in Python to practice string manipulation, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Select the Hidden Word

#### Description

Set up the game so it randomly chooses a hidden word from a predefined list.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list.

### 🛠️ Handle Player Guesses

#### Description

Allow the player to guess letters and reveal the hidden word before running out of attempts.

#### Requirements

Completed program should:

- Accept letter guesses from the player.
- Display the current progress using underscores for unguessed letters, such as `_ _ _`.
- Track and display the number of incorrect guesses remaining.
- End when the player guesses the word or runs out of attempts.
- Display a win message when the word is guessed and a lose message when attempts are exhausted.
